# House Price Prediction using Linear Regression

## Overview

Built an end-to-end machine learning pipeline to predict house prices using Linear Regression.

## Dataset

- 545 houses
- 13 original features
- Numerical and categorical attributes

## Workflow

- Data Cleaning
- Exploratory Data Analysis
- Feature Encoding
- Train-Test Split
- Linear Regression
- Model Evaluation

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Results

MAE : 970043

RMSE : 1324507

R² Score : 0.653
